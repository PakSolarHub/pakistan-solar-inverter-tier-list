# Pakistan Solar Inverter Tier List 🇵🇰

An independent, evidence-based tier list and database of solar inverters available in Pakistan.

## What this project is

The goal is to build a Pakistani equivalent of a community hardware tier list: easy for buyers to use, but backed by transparent research.

We will evaluate:

- Hardware/platform quality
- Reliability evidence
- Warranty and warranty handling
- Pakistani distributor/service support
- Features and technical capability
- OEM/platform transparency
- Value for money
- Monitoring/software

## Current status

**v0.1 — foundation and research phase.**

Initial inverter records are intentionally **UNRATED** until sufficient evidence is collected. No model should receive a final tier merely because it is popular or because one person reports a good/bad experience.

## Tier system

| Tier | Meaning |
|---|---|
| S | Exceptional |
| A | Strong recommendation |
| B | Good / price dependent |
| C | Significant compromises |
| D | Generally avoid |
| UNRATED | Insufficient evidence |

## Evidence confidence

- **High** — manufacturer documentation, independent testing, or multiple strong sources
- **Medium** — credible distributor/installer evidence or limited independent evidence
- **Low** — community reports or indirect evidence
- **Unknown** — insufficient evidence

## Independence

This is an independent community project and is not affiliated with any inverter manufacturer, distributor or installer. Prices and availability change. Rankings are research opinions based on documented evidence and should not replace professional electrical/solar advice.
